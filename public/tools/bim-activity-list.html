How to get data out of an NWD file

The browser can't open .nwd files directly, so export the element list from Navisworks with either route:

  1. Selection Inspector: go to Options › Interface › Quick Properties and add Element › Category, Element › Level (or Item › Layer), plus Volume/Area/Length. Select all (Ctrl+A), open Home › Selection Inspector and click Export › CSV.
  2. Quantification: run Model Takeoff on the model, then use Import/Export › Export quantities to Excel.
  3. An IFC file of the same model (for example from Revit) also works here.
