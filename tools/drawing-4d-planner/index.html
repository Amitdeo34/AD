What the reader extracts from each format
  • DXF (best) — layers, blocks/INSERT counts, LINE/POLYLINE lengths, closed-polyline & circle areas, TEXT/MTEXT with coordinates, dimensions, grid bubbles. Real quantities come from here.
  • PDF (vector, AutoCAD plot) — every text item with its X/Y position: sheet number, title, scale, level, grid labels, element marks (C1, B2, W-101…), room names, schedules printed on the sheet.
  • PDF (scanned raster) — no embedded text, so only the image is shown. Mark the quantities manually in step 3, or re-plot the drawing to PDF from AutoCAD.
  • DWG — a closed binary format; no browser can parse it. Export DXF (2013 ASCII) or plot a PDF and load that.

How measuring works
  • count — number of blocks/marks (columns, doors, windows, fixtures).
  • length — total length of lines/polylines on the layer, in metres (walls, pipes, ducts, trays).
  • area — area of closed polylines/circles, in m² (slabs, floors, plaster, waterproofing).
  • volume — area × factor (factor = thickness in m) for slabs, rafts, PCC.
  • Factor also converts counts to work units, e.g. one column = 0.48 m³ concrete.

9 · Exports

All exports are generated in your browser from the developed schedule.

Primavera P6 .xer

Full XER: PROJECT, CALENDAR, PROJWBS, TASK, TASKPRED. Import in P6 via File → Import → XER. Seedha P6 me import ho jayega.

Detailed schedule .xlsx

Workbook: Schedule, WBS, Relationships, Quantities, Norms, Assumptions, S-curve data.

BIM 4D update .xlsx

Navisworks TimeLiner / Synchro ready: task name, type, planned start/finish, search-set name, level, zone, element marks and GUIDs, appearance.

MS Project .xml

Project XML with WBS, durations, dates and links — opens in MS Project, Asta and most planning tools.

How to use the BIM 4D file in Navisworks
  • Open the model → TimeLiner → Data Sources → Add → CSV / Excel and pick the exported file.
  • Field selector: Task Type = Task Type, Planned Start = Planned Start, Planned End = Planned End, and Synchronisation on Search Set or Display ID.
  • Create search sets with the same names (the Search Set column follows Level_Zone_Category), then Auto-Attach Using Rules.
  • Simulate → Settings → set the interval and export the AVI. Search set ke naam bilkul same rakho, warna attach nahi hoga.
